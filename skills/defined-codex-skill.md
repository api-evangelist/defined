# Codex API skill

This is a reference to the **official Codex agent skill** published by Defined at
`github.com/Codex-Data/skills`. It is not generated by API Evangelist — it is the
provider's own packaged skill, captured here so the network can point agents at
it. Install it into your coding agent with:

```bash
npx skills add Codex-Data/skills -g --yes
```

## What the published skill packages

- **Operation mapping** — routes user intent to the right GraphQL query.
- **Authentication patterns** — handles both the API-key header and the Machine
  Payments Protocol (MPP) HTTP 402 payment flow. See
  `authentication/defined-authentication.yml`.
- **Query templates** — pre-built GraphQL examples for common tasks such as
  `filterTokens` and `getTokenPrices`.
- **Endpoint playbook** — a decision guide for choosing the right operation
  based on intent.
- **Network validation** — a required `getNetworks` preflight before requests,
  because `networkId` is required on most token/pair queries. See
  `conventions/defined-conventions.yml`.

## Coverage

Token discovery, pricing, charts, events, wallet analytics, holder information
and prediction markets — as one-time queries and as real-time subscriptions over
graphql-ws (see `asyncapi/defined-webhooks.yml`).

## Endpoint

- GraphQL: `POST https://graph.codex.io/graphql`
- Subscriptions: `wss://graph.codex.io/graphql` (graphql-ws)
- Auth: `Authorization: <API_KEY>` (no Bearer prefix)
